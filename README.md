# Philosophy Jeopardy Game

This project provides a browser-based Jeopardy style review game for philosophy topics. To play:

1. Open `index.html` in a modern web browser.
2. Choose a topic from the selector at the top of the page.
3. Click a cell on the board to reveal a question and type your answer.
4. If your answer matches, the game continues. If it does not, the correct answer is shown. You may override mistakes in case of a typo.
5. After all questions are answered, a celebration screen appears. Click **Play Again** to restart.
